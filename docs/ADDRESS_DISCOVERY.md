## 별도 남은 작업

Xtoon의 안내는 `newxtoon1.com`을 가리키지만 새 사이트의 목록·회차 경로가 기존 구현과 다르다. 상세 화면은 회차 일부만 노출한다. 로컬 HTTP 클라이언트와 브라우저의 HTTPS 연결이 재설정되어 원본 HTML·전체 회차 API·기존 URL 호환성을 검증하지 못했다. 새 호스트만 허용해 미완성 파서로 자동 전환하지 않았으며, Xtoon은 이번 배포 범위에서 제외한다. Toonkor도 확인된 공식 안내 주소가 없어 이번 브랜치에 포함하지 않는다.
