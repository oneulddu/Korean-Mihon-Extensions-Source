## Xtoon 후속 수정 — 런타임 접속 검증 대기

- 새 콘텐츠 사이트가 직접 연결하는 공식 안내 `https://xn--vg1b002axlc8ts.com/`과 공식 공개 채널 `https://t.me/s/newxtoon`을 사용한다. 확인한 주소는 `https://newxtoon1.com`이다. 이전에 등록된 안내 도메인 `xn--9t4b31dr7o.com`과는 다른 주소다.
- 새 `/comics`, `/search?q=...`, `/comics/{id}/chapters/{id}` 구조에 맞춰 목록·검색·상세·회차·이미지 파서를 변경했다. 필터는 새 사이트에서 확인한 값만 사용하며, 실제 다음 페이지 링크가 있을 때만 계속 조회한다.
- 회차는 상세의 `section#chapters` 첫 목록과 `data-chapters-url`의 JSON 페이지를 끝까지 합친다. 중복·순환·부분 목록을 감지하며 번호나 회차 URL을 임의로 생성하지 않는다. 뷰어는 `img[data-reader-image]`와 부모의 `data-image-position`을 사용하고 이미지 오류 처리 코드의 총 개수 힌트로 마지막 이미지 누락도 검사한다.
- 소스 이름·ID·언어·versionId는 유지한다. 옛 `/comic/{id}`는 새 데이터베이스와 ID 대응이 입증되지 않아 같은 번호로 치환하지 않는다. 저장된 제목의 유일한 정확 일치 검색 결과를 상세에서 재확인하고, 작가 정보가 있으면 교집합을 확인한 뒤 매핑을 저장한다. 이름이 바뀌거나 중복·불일치가 있으면 Mihon의 소스 이전을 안내한다. 옛 `/chapter/{id}`는 작품 문맥이 없어 새 회차로 추정하지 않고 목록 새로고침을 안내한다. 과거 읽음 기록까지 자동 이전된다는 보장은 없다.
- 수동 URL, 자동 캐시, 주소 재시도 우선순위를 유지한다. 이미지 CDN 요청은 주소 재작성 대상에서 제외하고 실제 회차 URL을 Referer로 보낸다.

### 확보한 근거와 검증 범위

2026-09-09의 공개 원본 HTML과 JSON을 Jina Reader로 수집해 개발용 근거로 사용했다. 확장 런타임에는 Jina나 프록시 경로를 넣지 않았다. 테스트 자료는 광고 카드 구분·파서 속성·회차 데이터만 남기고 폼과 세션 토큰 등을 제거했다.

- 인기 목록의 24개 카드 중 1개는 광고다. 실제 작품 23개와 다음 페이지 링크를 확인했다.
- 화산귀환(`/comics/1876`)의 첫 20개 + API 2~8페이지 각 20개 + 마지막 18개 = 178개다. 뷰어의 전체 회차 178개와 ID 집합·순서까지 일치한다. 마지막 API는 `has_more=false`, `next_page=null`이다.
- 1화(`/comics/1876/chapters/139884`)는 본문 이미지 146개다. 첫 이미지는 실제 회차 Referer를 사용한 직접 GET이 HTTP 200이며 690×1600 WebP로 디코딩됐다.
- 화산귀환 검색에서 정확한 제목 일치 1건을 확인했다. 검색 결과에 없는 다음 페이지를 추측하지 않는다.
- 모듈 `spotlessCheck`, `testDebugUnitTest`, `assembleRelease` 통과, 테스트 17개 실패 0개다. 회차 전체 수집, 파서 범위, 페이지 진행, 도메인 검증, 안내 장애 복구, 이미지 순서·누락을 테스트한다.

기존 API 35 Android 에뮬레이터에 수정 APK를 설치했고 Mihon에서 Xtoon 소스 등록, 수동 주소가 비어 있는 상태, 공식 안내를 통한 `newxtoon1.com` 자동 저장과 출처 표시를 확인했다. 그러나 목록 요청은 `ConnectException`으로 실패했고 WebView에서도 `net::ERR_CONNECTION_RESET`이 발생했다. **실제 Mihon 목록·상세·회차·뷰어 성공 검증은 아직 완료하지 못했다.** 저장소 규칙에 따라 `extVersionCode`는 6을 유지하고 Xtoon 수정의 커밋·푸시는 보류한다. 연결 가능한 환경에서 런타임 검증을 완료한 뒤 버전 인상과 배포를 진행해야 한다.

Toonkor는 확인된 공식 안내 주소가 없어 이번 브랜치에 포함하지 않는다.
