## 정비 범위

9개 확장의 소스 이름, ID, 언어를 유지한다. 저장된 작품·회차 URL은 가능한 범위에서 호환하며, 새 사이트로 개편된 Xtoon의 이전 주소 처리는 아래에 별도로 기록한다. 사이트마다 다른 HTML과 API는 각 확장에 남기고, 주소 검증·요청 재작성과 파서·캐시의 실패 처리 규칙을 맞춘다.

- 공통 주소 탐색: 진행 중인 결과 공유, 네트워크를 상태 잠금 밖에서 실행, 캐시 초기화 뒤 오래된 결과 무효화, 실패 시 마지막 정상 주소 유지. `Origin`은 경로 없는 origin 형식으로 전송한다.
- NTK: 전체 수동 URL 설정과 공통 자동 주소 캐시, WebView 종료와 예약 작업 정리, 회차 API 검증 실패 시 HTML 대체 수집, 이미지 순서와 지연 로딩 속성 처리, JSON 문자열 경계 처리, 광고 확인 쿠키 수명 일관성.
- 블랙툰: 목록 캐시 만료, 실패 시 이전 목록 유지, 페이지 이동 중 조회 결과 고정, 정렬 재사용과 필요한 범위만 추출, 날짜 파서 동시 접근 보호. 목록·회차·이미지 CDN 설정과 쿼리를 반영하고, 실제 접속을 확인한 421 주소를 빌드 기본값에 반영했다.
- 늑대닷컴: 검색 조건별 목록 캐시와 페이지 범위 검사.
- 짭툰: 수동 주소가 설정된 동안에도 기존 사이트 이미지 요청을 수동 주소로 재작성.
- Xtoon: 새 사이트 목록·상세·회차 JSON 페이지·뷰어 파서, 공식 안내와 공식 채널 주소 탐색, 이전 작품의 제목 기반 연결과 불확실한 이전 회차 안내.
- 11toon: 인기·검색 요청 페이지 반영, 실제 다음 페이지 판단, 장르 인코딩 수정.
- 네이버·툰코르: 검색어를 쿼리 파라미터로 인코딩.
- RawDEX/Madara: 동일 DOM 이미지의 중복 선택 방지와 srcset 해상도 선택. 다른 DOM 위치에 있는 동일 URL 이미지는 보존한다. RawDEX는 Nova 테마의 목록·검색·상세·회차·뷰어 구조를 전용 파서로 지원한다.
- 배포: 숫자 버전 비교, 현재 소스 버전과 APK 일치 및 요청한 APK 누락 검사, APK 빌드 없이 삭제된 확장 인덱스 정리. Kotlin 회귀 테스트를 PR과 배포 검사에 포함한다.

## 주소·캐시 호환성

NTK의 옛 도메인 번호는 자동 갱신과 사용자 입력이 같은 키에 저장되어 있어 수동 설정 여부를 판별할 수 없다. 기존 번호는 자동 캐시로 이관하며 새 수동 URL은 사용자가 명시적으로 입력한 경우에만 저장한다. `baseUrl` 등 UI에서 읽는 속성에서는 네트워크 탐색을 실행하지 않는다.

자동 주소는 수동 URL → 유효 자동 캐시 → 공식 안내/공식 API → HTTP 리다이렉트 → 만료된 마지막 정상 캐시 → 빌드 기본값 순서로 결정한다. NTK에는 이 변경에서 검증된 공식 안내 페이지가 없어 리다이렉트부터 시도한다. 자동 호스트는 사이트별 패턴으로 제한하고 외부 CDN URL은 유지한다. 주소 캐시는 12시간, 실패 재시도는 15분, 탐색 클라이언트 제한은 8초다.

블랙툰 작품 목록 캐시는 주소 캐시와 별도로 15분을 사용하며 갱신은 첫 페이지에서만 반영한다. 다음 페이지는 같은 검색 조건의 기존 목록과 순서를 사용한다. 캐시가 제거된 후의 조회는 다시 목록을 얻어 안전한 범위로 처리한다.

## 검증

구현 전 기준 검사: Kotlin 18개, Python 5개 통과.

구현 후 단위 테스트, 릴리스 빌드, 독립 코드 리뷰와 Mihon Android 검증 결과는 아래에 확정된 결과만 기록한다. 단위 테스트·HTTP 응답·컴파일 성공을 실제 뷰어 성공으로 간주하지 않는다.

### Android 기준 상태

기존 `ntk-runtime-api35` 에뮬레이터와 설치된 Mihon을 재사용한다. NTK v14에서 원피스 목록·상세와 1,295개 회차, 1188화의 13장 이미지 중 첫 이미지 표시를 확인했다. 기존 확장 APK를 임시 경로에 백업한 뒤 서명이 다른 확장 패키지를 재설치했다. Mihon 앱의 데이터·라이브러리·설정은 유지했다. 새 APK는 Mihon에서 신뢰 처리하고 검증했다.

### 구현 후 결과

- 공통 변경 전체: Kotlin 회귀 테스트 86개, Python 12개, JavaScript 2개 통과. Spotless와 9개 확장의 명시적 `assembleRelease` 작업 통과.
- RawDEX 추가 수정: Kotlin 7개, 모듈 Spotless, Debug/Release 빌드 통과. 이후 블랙툰 CDN 파서 19개를 추가하여 최종 Kotlin 합계 112개이며 실패·건너뜀은 없다. 전체 Spotless·단위 테스트와 마지막 변경 확장의 Release 빌드를 다시 통과했다.
- 배포 인덱스는 실제 APK 9개/소스 14개로 임시 경로에서 생성했다. YAML 파싱과 워크플로 셸 구문 검사도 통과했다.
- Opus 계획 검토와 별도 Astra 코드 리뷰를 거쳤다. 최종 리뷰의 도메인 리다이렉트 캐시 누락, 늑대닷컴 취소 전파 회귀를 수정하고 관련 테스트·빌드를 다시 통과했다. RawDEX와 블랙툰 CDN 추가 변경도 별도 읽기 전용 리뷰에서 P1/P2 지적이 없었다.

NTK Webtoon은 기존 설정에서 소스가 비활성화돼 있었다. 검증 중 잠시 활성화했고 전체 수동 HTTPS URL 입력·저장과 값을 비운 뒤 자동 모드로 복귀하는 동작을 확인한 후 기존 비활성 상태로 복원했다. 블랙툰의 수동 주소도 검증 후 기존 설정으로 복원했다. 실행 로그와 화면에서 API·WebView 오류를 확인하며, 외부 이미지 서버 연결 실패를 이미지 표시 성공으로 처리하지 않는다.

런타임 검증이 막힌 확장이 있어 전체 변경의 배포 조건은 아직 충족하지 못했다. 증거 화면과 사이트 HTML은 저장소 밖의 임시 검증 경로에 두고 커밋하지 않는다.

### 9월 9일 주소 탐색 후속 수정

짭툰의 안내 사이트 이동과 JSON API, 늑대닷컴 공식 공개 채널 보조 탐색을 추가했다. 관련 신규 테스트 11개와 두 확장의 Android 자동 연결·뷰어 검증을 통과했다. 별도 브랜치 `feature/address-guides-0909`에는 이 주소 탐색 수정만 분리하여 커밋 `477325513f`로 푸시했고, 당시 해당 작업 트리는 깨끗했고 로컬·원격 SHA가 일치했다. 현재는 그 위에 Xtoon의 미커밋 후속 수정이 있다. 짭툰 버전은 15, 늑대닷컴은 12다. 최종 분리 브랜치의 단위 테스트는 17개 모두 통과했다. 세부 근거는 [공식 주소 안내 복구](ADDRESS_DISCOVERY.md)에 기록한다.

기존 전체 정비 브랜치 `feature/source-consistency-0908`의 공통 코어, 목록 캐시, 수동 요청 재작성 등 나머지 변경은 이 푸시에 포함하지 않고 보존했다. 전체 정비를 배포할 때는 위 주소 탐색 커밋을 기준에 반영하고, 그 뒤 추가 동작 변경이 있는 확장의 버전을 다시 상향해야 한다.

Xtoon은 새 `/comics`와 `/comics/{id}/chapters/{id}` 구조의 파서까지 후속 수정했다. 공개 원본 HTML·JSON을 개발용으로 확보해 화산귀환의 전체 178개 회차와 뷰어 146개 이미지 구조를 검증했다. 원본 확보에 사용한 Jina Reader는 확장에 포함하지 않는다. 공식 안내를 통한 자동 주소 저장은 실제 Mihon에서 확인했지만 콘텐츠 연결은 계속 실패하여 목록·상세·회차·뷰어 실검증은 미완료다. 테스트 17개, 모듈 Spotless, Release 빌드는 통과했다. 이전 작품은 제목의 유일한 정확 일치와 가능한 작가 정보로 확인하고, 대응이 불명확하면 소스 이전을 안내한다. 옛 회차 URL·읽음 기록의 자동 이전까지 보장하지 않는다. 버전은 6으로 유지하고 Xtoon의 커밋·푸시를 보류했다. 동일한 최종 소스를 전체 정비 작업 트리에도 반영했으며 이전 Xtoon 작업 파일은 `/tmp/xtoon-before-new-site-0909`에 백업했다.

### 배포 전 전체 재검증 (2026-09-09)

루트 `spotlessCheck`와 `testDebugUnitTest`를 통과했다. Kotlin 테스트 133개, Python 12개, JavaScript 2개 모두 실패·건너뜀 없이 통과했다. 루트 검사에서 확인된 Xtoon 테스트 import·줄바꿈 형식을 수정했고, 같은 테스트 파일을 주소 안내 작업 트리에도 동기화했다. 런타임 접속 실패 항목의 배포 조건은 별개로 유지한다.

짭툰 1.4.15·늑대닷컴 1.4.12 주소 복구는 워크플로 `34280561275`로 배포를 완료했다. 배포 커밋 `19ec5a8db007bb4f41457750648e5120e15b534b`의 인덱스, 공개 APK 패키지·버전·서명을 확인했다. 그 외 전체 정비 변경은 이번 배포에 포함되지 않았다.

### 전체 배포 예외 지시 (2026-09-09)

미검증 항목의 포함 여부를 확인하고 짭툰·늑대닷컴만 먼저 배포한 뒤, 사용자가 “일단 배포부터 진행하자”라고 재차 지시했다. 이번 배포는 이 지시에 따라 전체 9개 확장을 포함하며, 접속 실패 항목의 Mihon 실검증 완료를 배포 전제에서 일회성으로 제외한다. AGENTS.md의 일반 규칙은 변경하지 않는다.

- 여전히 미완료: Xtoon·Toonkor의 목록/상세/회차/뷰어 접속, NTK Webtoon의 실제 이미지 표시.
- 일부 작품의 회차 번호 공백·혼합 단위에 따른 Missing chapters 표시는 위 Android 표와 같다.
- 테스트 성공과 배포 성공은 해당 사이트의 실제 이용 성공을 뜻하지 않는다.
